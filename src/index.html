UnCam
Телефон

Подключи телефон кабелем. Отладка по USB должна быть включена, а на телефоне — разрешение для этого компьютера.

Первое подключение (сопряжение)

На телефоне: Для разработчиков → Отладка по Wi-Fi → Подключить устройство с помощью кода. Введи адрес и код с экрана.

Камера

UnCam откроет на телефоне обычную «Камеру» в режиме видео и будет брать картинку с экрана. Так Xiaomi отдаёт 60 fps. Включи в «Камере» 60 к/с, а лишние кнопки обрежь кнопкой «Обрезать» на превью.
